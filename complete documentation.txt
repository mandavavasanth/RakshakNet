## Executive Summary

**RashakNet** is a comprehensive disaster emergency response management system designed to coordinate rescue operations during emergencies. The system enables:

- **Real-time Alert Management**: Receive, track, and manage emergency alerts from IoT devices
- **Team Coordination**: Assign rescue teams to alerts and monitor deployment status
- **Live Dashboard**: Real-time web interface with map-based alert visualization
- **Hardware Integration**: Connect Arduino/LoRa devices for emergency notifications
- **WebSocket Broadcasting**: Push real-time updates to all connected dashboard clients
- **Analytics & Statistics**: Monitor response times and alert statistics
- **Secure API**: X-API-Key authentication for hardware ingestion endpoints

**Key Features:**
- ✅ Multi-alert type support (SOS, Medical, Water, Food)
- ✅ Geographic mapping with latitude/longitude coordinates
- ✅ Real-time WebSocket event streaming
- ✅ PostgreSQL database with Alembic migrations
- ✅ REST API with comprehensive filtering
- ✅ Chat & communication features
- ✅ Audit logging & compliance tracking
- ✅ Mobile-responsive React dashboard

### Data Flow

1. **Alert Creation**: Arduino device → Serial bridge → POST /api/alert → Database

4. **Status Update**: WebSocket notification → Dashboard (real-time refresh)

## Backend Setup & Configuration

### Step 1: Install Python Dependencies

```bash
cd d:\RAKSHAKNET
pip install -r requirements.txt
```

**Dependencies include:**
- fastapi, uvicorn (web server)
- sqlalchemy, psycopg2-binary (database)
- alembic (migrations)
- websockets (real-time)
- pydantic (validation)
- python-dotenv (env config)

### Step 2: Configure Environment Variables

Create or update `.env` file in the project root:

```env
# Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_NAME=rashaknet_db
DB_USER=postgres
DB_PASSWORD=your_secure_password
DB_ECHO=False

# FastAPI Configuration
API_KEY=rashaknet-secret-key-2026
FRONTEND_URL=http://localhost:5173

# Supabase Configuration (Optional)
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key

# Server Configuration
ENVIRONMENT=development
LOG_LEVEL=INFO
```

### Step 3: Set Up PostgreSQL Database

If using PostgreSQL (recommended for production):

```bash
# 1. Ensure PostgreSQL is running
# 2. Create database
psql -U postgres -c "CREATE DATABASE rashaknet_db;"

# 3. Create user (optional)
psql -U postgres -c "CREATE USER rashaknet_user WITH PASSWORD 'password123';"
psql -U postgres -c "ALTER ROLE rashaknet_user CREATEDB;"
```

**SQLite Fallback**: If PostgreSQL is unavailable, the system automatically uses `rashaknet.db` SQLite file.

### Step 4: Run Database Migrations

```bash
# Initialize migrations (if needed)
alembic init alembic

# Apply all pending migrations
alembic upgrade head

# Create new migration after model changes
alembic revision --autogenerate -m "Description of changes"
```

### Step 5: Start FastAPI Server

```bash
# Development (with hot reload)
uvicorn main:app --reload --port 8000

# Production
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

**API Documentation**:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

## API Endpoints Specification

### Emergency Alerts Endpoints

#### 1. **Create Alert** (POST)
```http
POST /api/alert
Header: X-API-Key: rashaknet-secret-key-2026
Content-Type: application/json

{
  "deviceId": "DEV001",
  "helpType": "Medical",
  "lat": 17.3850,
  "lng": 78.4867,
  "timestamp": "2026-08-13T17:32:00Z"  # Optional; uses current time if omitted
}
```

**Response** (201 Created):
```json
{
  "id": 1,
  "deviceId": "DEV001",
  "helpType": "Medical",
  "lat": 17.3850,
  "lng": 78.4867,
  "timestamp": "2026-08-13T17:32:00Z",
  "status": "Pending",
  "assignedTeam": null
}
```

**Error Responses**:
- `401 Unauthorized`: Missing or invalid X-API-Key
- `422 Unprocessable Entity`: Invalid request body

---

#### 2. **List Alerts** (GET)
```http
GET /api/alerts?status=Pending&helpType=Medical&from_date=2026-08-01T00:00:00Z&to_date=2026-08-14T00:00:00Z
```

**Query Parameters**:
| Parameter | Type | Optional | Description |
|-----------|------|----------|-------------|
| `status` | string | Yes | Filter by status: `Pending`, `Assigned`, `Completed` |
| `helpType` | string | Yes | Filter by type: `SOS`, `Medical`, `Water`, `Food` |
| `from_date` | ISO datetime | Yes | Alerts from this date forward |
| `to_date` | ISO datetime | Yes | Alerts up to this date |

**Response** (200 OK):
```json
[
  {
    "id": 1,
    "deviceId": "DEV001",
    "helpType": "Medical",
    "lat": 17.3850,
    "lng": 78.4867,
    "timestamp": "2026-08-13T17:32:00Z",
    "status": "Pending",
    "assignedTeam": null
  },
  {
    "id": 2,
    "deviceId": "DEV002",
    "helpType": "SOS",
    "lat": 17.3900,
    "lng": 78.4900,
    "timestamp": "2026-08-13T17:28:00Z",
    "status": "Assigned",

]
```

## Database Schema

### Table: `alerts`

```sql
CREATE TABLE alerts (
  id INTEGER PRIMARY KEY AUTO_INCREMENT,
  deviceId VARCHAR(255) NOT NULL INDEXED,
  helpType VARCHAR(50) NOT NULL INDEXED,      -- SOS, Medical, Water, Food
  lat FLOAT NOT NULL,                          -- Latitude coordinate
  lng FLOAT NOT NULL,                          -- Longitude coordinate
  timestamp DATETIME NOT NULL DEFAULT NOW(),   -- Alert creation time
  status VARCHAR(50) DEFAULT 'Pending' INDEXED, -- Pending, Assigned, Completed
  assignedTeam VARCHAR(255) NULLABLE           -- Name/ID of rescue team
);
```

**Indexes**: `deviceId`, `helpType`, `status`, `timestamp`

**Sample Data**:
```
id | deviceId | helpType | lat    | lng    | timestamp            | status   | assignedTeam
---+----------+----------+--------+--------+----------------------+----------+---------------
1  | DEV001   | Medical  | 17.385 | 78.487 | 2026-08-13 17:32:00 | Pending  | NULL
2  | DEV002   | SOS      | 17.398 | 78.495 | 2026-08-13 17:28:00 | Assigned | Alpha Team
3  | DEV003   | Food     | 17.374 | 78.472 | 2026-08-13 17:22:00 | Completed| Bravo Team
```

---

### Table: `rescue_teams`

```sql
CREATE TABLE rescue_teams (
  id INTEGER PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(255) NOT NULL UNIQUE INDEXED,
  status VARCHAR(50) DEFAULT 'Available' INDEXED, -- Available, Deployed
  members INTEGER DEFAULT 4                    -- Team member count
);
```

**Indexes**: `name`, `status`

**Sample Data**:
```
id | name         | status     | members
---+--------------+------------+--------
1  | Alpha Team   | Available  | 5
2  | Bravo Team   | Deployed   | 4
3  | Charlie Team | Available  | 6
```

## WebSocket Events

### Connection
```javascript
// Client connects to WebSocket endpoint
const ws = new WebSocket('ws://localhost:8000/ws/alerts');

ws.onopen = () => {
  console.log('Connected to alert stream');
};
```

### Broadcasting Events

#### Event: `new_alert`
Sent when a new emergency alert is created:

```json
{
  "event": "new_alert",
  "data": {
    "id": 1,
    "deviceId": "DEV001",
    "helpType": "Medical",
    "lat": 17.3850,
    "lng": 78.4867,
    "timestamp": "2026-08-13T17:32:00Z",
    "status": "Pending",
    "assignedTeam": null
  }
}
```

#### Event: `alert_updated`
Sent when an alert status or assignment changes:

```json
{
  "event": "alert_updated",
  "data": {
    "id": 1,
    "status": "Assigned",
    "assignedTeam": "Alpha Team"
  }
}
```

#### Event: `team_status_changed`
Sent when a team's deployment status changes:

```json
{
  "event": "team_status_changed",
  "data": {
    "teamId": 1,
    "teamName": "Alpha Team",
    "status": "Deployed"
  }
}
```

### Client-Side Implementation (React)

```javascript
import { useEffect, useState } from 'react';

export function AlertsComponent() {
  const [alerts, setAlerts] = useState([]);

  useEffect(() => {
    const ws = new WebSocket('ws://localhost:8000/ws/alerts');

    ws.onmessage = (event) => {
      const message = JSON.parse(event.data);
      
      if (message.event === 'new_alert') {
        setAlerts(prev => [message.data, ...prev]);
      } else if (message.event === 'alert_updated') {
        setAlerts(prev => 
          prev.map(alert => 
            alert.id === message.data.id 
              ? { ...alert, ...message.data }
              : alert
          )
        );
      }
    };

    return () => ws.close();
  }, []);

  return (
    <div>
      {alerts.map(alert => (
        <div key={alert.id}>{alert.deviceId} - {alert.helpType}</div>
      ))}
    </div>
  );
}
```

## Hardware Integration

### Serial Bridge Architecture

The **Serial Bridge** (Python) connects Arduino/LoRa devices to the FastAPI backend:

```
Arduino Mega (USB) → PySerial → Serial Bridge → POST /api/alert → Database
```

### Serial Bridge Installation

```bash
# Navigate to serial_bridge directory
cd serial_bridge

# Install dependencies
pip install -r requirements.txt
# Installs: pyserial, requests, python-dotenv

# Run bridge with specific COM port
python bridge.py --port COM3 --baud 9600
```

### Arduino Serial Data Format

The bridge accepts two formats from Arduino:

#### Format A: JSON (Recommended)
```json
{
  "node_id": "01",
  "status": "EMERGENCY",
  "latitude": 16.544893,
  "longitude": 81.521240
}
```

#### Format B: Comma-Separated Key-Value Pairs
```
NODE:01,STATUS:EMERGENCY,LAT:16.544893,LNG:81.521240
```

### Bridge Configuration (`.env`)

```env
# Supabase endpoints
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key

# Or FastAPI endpoint
FASTAPI_URL=http://localhost:8000
API_KEY=rashaknet-secret-key-2026
```

### Bridge Processing Logic

1. **Receive** data from Arduino serial port
2. **Parse** JSON or key-value format
3. **Validate** coordinates and device ID
4. **POST** to `/api/alert` with X-API-Key header
5. **Log** success/failure to console

### Example Arduino Code

```cpp
#include <ArduinoJson.h>
#include <SoftwareSerial.h>

// Create JSON document
StaticJsonDocument<200> doc;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // On emergency trigger
  if (emergencyButtonPressed) {
    doc["node_id"] = "01";
    doc["status"] = "EMERGENCY";
    doc["latitude"] = getGPS_Latitude();
    doc["longitude"] = getGPS_Longitude();
    
    // Serialize and send
    serializeJson(doc, Serial);
    Serial.println();
    
    delay(1000);
  }
}
```

### Development Deployment

```bash
# 1. Clone repository
```

### Production Deployment (Linux/Ubuntu)

#### Option 1: Using Systemd

**Create FastAPI Service** (`/etc/systemd/system/rashaknet-api.service`):
```ini
[Unit]
Description=RashakNet FastAPI Service
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/rashaknet
Environment="PATH=/var/www/rashaknet/venv/bin"
ExecStart=/var/www/rashaknet/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```

**Create Node.js Service** (`/etc/systemd/system/rashaknet-node.service`):
```ini
[Unit]
Description=RashakNet Node.js Server
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/rashaknet
ExecStart=/usr/bin/node server.js
Restart=always

[Install]
WantedBy=multi-user.target
```

**Enable and start**:
```bash
sudo systemctl enable rashaknet-api
sudo systemctl start rashaknet-api
sudo systemctl enable rashaknet-node
sudo systemctl start rashaknet-node
```

#### Option 2: Using Docker

Create `Dockerfile`:
```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

Build and run:
```bash
docker build -t rashaknet-api .
docker run -p 8000:8000 --env-file .env rashaknet-api
```

#### Option 3: Using Nginx Reverse Proxy

```nginx
upstream fastapi {
    server 127.0.0.1:8000;
}

upstream nodejs {
    server 127.0.0.1:5001;
}

server {
    listen 80;
    server_name api.rashaknet.com;

    # FastAPI
    location /api/ {
        proxy_pass http://fastapi;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # WebSocket
    location /ws/ {
        proxy_pass http://fastapi;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # Node.js
    location / {
        proxy_pass http://nodejs;
        proxy_set_header Host $host;
    }
}
```

## Troubleshooting & FAQs

### Backend Issues

**Q1: PostgreSQL Connection Failed**
```
Error: could not translate host name "localhost" to address
```
**Solution**:
- Ensure PostgreSQL is running: `sudo systemctl start postgresql`
- Check credentials in `.env`
- Verify database exists: `psql -l`
- System falls back to SQLite if PostgreSQL unavailable

---

**Q2: API Key Authentication Failing**
```
Error: Invalid X-API-Key header
```
**Solution**:
- Verify `X-API-Key` header is included in request
- Check header value matches `.env` `API_KEY`
- Example: `curl -H "X-API-Key: rashaknet-secret-key-2026" http://localhost:8000/api/alerts`

---

**Q3: WebSocket Connection Not Streaming**
```
WebSocket connection established but no events received
```
**Solution**:
- Verify WebSocket endpoint: `ws://localhost:8000/ws/alerts`
- Check browser console for errors
- Ensure FastAPI server is running with `--reload` disabled in production
- Test with: `websocat ws://localhost:8000/ws/alerts`

---

**Q4: Alembic Migration Failed**
```
Error: Can't locate revision identified by...
```
**Solution**:
```bash
# Reset to initial state (development only)
alembic downgrade base
alembic upgrade head

# Or re-initialize
rm alembic/versions/*.py
alembic revision --autogenerate -m "Initial"
alembic upgrade head
```

---

### Frontend Issues

**Q5: Port 5173 Already in Use**
```
Error: Port 5173 is already in use
```
**Solution**:
```bash
# Use different port
npm run dev -- --port 5174

# Or kill existing process
lsof -ti:5173 | xargs kill -9  # macOS/Linux
netstat -ano | findstr :5173   # Windows
```

---

**Q6: CORS Errors**
```
Access to XMLHttpRequest blocked by CORS policy
```
**Solution**:
- Verify FastAPI has CORS middleware enabled (check main.py)
- Update `FRONTEND_URL` in backend `.env`
- For development: `allow_origins=["*"]`

---

**Q7: WebSocket Connected but No Real-Time Updates**
```
WebSocket says connected but alerts don't refresh
```
**Solution**:
- Check browser Network tab → WS connection
- Verify alert POST to `/api/alert` succeeds
- Check browser console for JavaScript errors
- Test with: `curl -X POST http://localhost:8000/api/alert ...`

---

### Hardware Integration Issues

**Q8: Serial Bridge Can't Find Arduino**
```
Error: Serial port COM3 not found
```
**Solution**:
```bash
# List available ports
python -m serial.tools.list_ports

# Use correct port
python bridge.py --port COM4 --baud 9600

# Check Arduino IDE device manager for port
```

---

**Q9: Serial Data Parsing Fails**
```
Error: Failed to parse serial data
```
**Solution**:
- Verify Arduino sends JSON or KEY:VALUE format
- Check baud rate matches (default 9600)
- Add serial monitor logging to Arduino code
- Test with: `python -m serial.tools.miniterm COM3 9600`

---

### Database Issues

**Q10: SQLite Database Locked**
```
Error: database is locked
```
**Solution**:
```bash
# Close any other processes
lsof rashaknet.db

# Check database integrity
sqlite3 rashaknet.db "PRAGMA integrity_check;"

# Recreate if corrupted
rm rashaknet.db
alembic upgrade head
```

## Security & Best Practices

### API Security

#### 1. X-API-Key Authentication
```python
# All POST endpoints require X-API-Key header
POST /api/alert
X-API-Key: rashaknet-secret-key-2026
```

**Best Practices**:
- ✅ Use strong, randomly generated keys (32+ characters)
- ✅ Store in `.env` (never in code)
- ✅ Rotate keys periodically in production
- ✅ Use different keys for dev/prod environments
- ✅ Log unauthorized attempts

#### 2. CORS Configuration
```python
# Production: Restrict to known domains
allow_origins=[
    "https://dashboard.rashaknet.com",
    "https://mobile.rashaknet.com"
]
```

#### 3. HTTPS/TLS
```nginx
# Use Let's Encrypt SSL certificates
server {
    listen 443 ssl;
    ssl_certificate /etc/letsencrypt/live/api.rashaknet.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.rashaknet.com/privkey.pem;
}
```

### Data Protection

#### Database
- ✅ Use PostgreSQL in production (not SQLite)
- ✅ Enable backups: `pg_dump -h host -U user -d rashaknet_db > backup.sql`
- ✅ Set strong database password
- ✅ Restrict database access to application server only

#### Environment Variables
- ✅ Never commit `.env` to version control
- ✅ Use `.env.example` as template
- ✅ Use secrets manager in production (AWS Secrets Manager, HashiCorp Vault)

#### Logs
- ✅ Don't log sensitive data (API keys, passwords)
- ✅ Rotate logs regularly
- ✅ Secure log file permissions: `chmod 600 app.log`

### Rate Limiting

```python
# Add rate limiting to prevent abuse
from slowapi import Limiter
from slowapi.util import get_remote_address

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter

@app.post("/api/alert")
@limiter.limit("10/minute")
async def create_alert(...):
    pass
```
